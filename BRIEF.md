# Issue Desk — frozen product contract v1

A local review desk for a solo US software builder with a small support inbox. Load synthetic examples or a bounded JSON ticket bundle, select an unresolved ticket, retrieve similar resolved cases, inspect original text and resolution, then record a manual disposition with optional linked case and a note. Reopen and amend decisions; export the reviewed queue locally. No messages are sent.

Required scope: English UI, synthetic/demo disclosure, unresolved/reviewed filters, selected ticket detail, lexical search that always works, explicit optional local semantic retrieval, transparent method/score labels (similarity is not probability), original evidence side by side, explicit human decision (investigate / linked prior case / unrelated), durable versioned review history, restart persistence, conflict rejection across stale tabs, safe local JSON export and validated replacement import. Linking is allowed only to resolved cases in the current dataset, and requires an operator note. Review does not resolve, merge or close the underlying support ticket. No invented generated reply, root cause or severity.

Data: own fictional software tickets only in demonstration. Bundle {schemaVersion:1,tickets:[{id,title,body,status:'open'|'resolved',resolution}]} with unique IDs matching [A-Za-z0-9_-]{1,40}, 1–200 rows, title 1–160, body 1–4000, resolution 0–4000 characters (required for resolved cases, empty for open). No arbitrary path, URL, attachment, personal information or third-party corpus. Maximum import 1 MiB. Treat all text literally, including HTML and instruction-like text. Invalid input preserves last valid state.

AI role: optional bge-m3:latest embeddings through server-only Ollama at http://127.0.0.1:11434; expected digest 7907646426070047a77226ac3e684fbbe8410524f7b4a74d02837e43f2146bab; num_gpu:0. Check identity before use; timeout and malformed vector checks; no model pulls. Cosine similarity ranks at most five resolved cases, excludes selected ticket. No arbitrary threshold claim, no accuracy/benchmark claim. Lexical retrieval uses documented token overlap. On AI failure show failure and retain manual/lexical route; never label lexical output AI. Bind result to exact ticket and dataset revision; discard late result after selection/import changes. AI never commits a decision.

Node 22 native modules, browser JS/CSS, no dependencies or install downloads. App loopback only, expected Host and same-origin mutation checks, JSON content type and size limits, no CORS. Persistent JSON is atomic with revision compare-and-swap; serialize mutation transactions. Fail closed on corrupt saved state, preserve bytes. Explicit local state directory for reproducibility. Single local operator, not multi-account or hosted service; access isolation beyond local boundary is not claimed.

Viewer outcome: run the included fictional queue, inspect a prior case, save a manual review, confirm restart persistence, export a report and validate bounded replacement import. Explore optional local semantic retrieval only with an existing matching model. This adapted brief describes the product, not a promise of production readiness, commercial demand or an identical model score.
